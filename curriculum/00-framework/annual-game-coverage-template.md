# Annual Game Coverage Matrix

Use one copy per class. Use the exact term names `First Term`, `Second Term` and `Third Term`. The matrix is the minimum planning and production register, not a substitute
for the detailed lesson plan. Every row must have a playable game seed. Add a second row only when the
subject genuinely needs a separate game objective.

## Game state vocabulary

`planned` → `drafted` → `schema-valid` → `safety-reviewed` → `ece-reviewed` → `published`.
Use `blocked` with a reason. Use `deferred` only with an approved replacement week. A game that is
merely `planned` does not count as delivered coverage.

## Weekly quality gate

Before marking a week complete, verify every subject has:

- one distinct seed ID;
- one objective and success evidence;
- a concrete non-screen warm-up;
- a template and age-appropriate tier;
- a safe asset/fallback plan;
- at least one differentiation path;
- a home connection;
- a completed teacher lesson plan;
- schema, safety and ECCE review status.
