# Number Representation Progression for EliteKids

## Purpose

Children should not be expected to jump from counting loose objects directly to abstract numerals. A
number game should help the child transform the same quantity between connected representations.

```text
real objects → one-to-one count → groups/bundles → tally representation → numeral → number name → use/compare
```

This is especially important as quantities become too large to display as loose objects. When a child
recognises that one structured bundle contains five items, the child can reason about 40–50 without
counting every individual mark from the beginning.

## The key distinction

The **game item count** is the number of playable target questions/relationships. The **quantity inside
an item** may be much larger.

Example:

```text
Game: 8 playable items
Targets: 40, 41, 42, 43, 44, 45, 46, 47
Representation: bundles of five tally marks plus extra strokes
```

This remains an eight-item game. The child is not expected to count 40 separate game rounds.

## Representation ladder by learning stage

### Stage 1 — Concrete one-to-one counting

Use real or clearly illustrated objects. The child touches, moves or gives one object for each count
word.

```text
5 apples = 🍎 🍎 🍎 🍎 🍎 = 5
```

Teacher language:

> “Touch each apple once. How many apples are there?”

### Stage 2 — Structured groups

Arrange objects into familiar groups. For early learners, a five-frame, ten-frame, egg tray, bottle-cap
line or group of five safe counters makes quantity visible.

```text
10 objects = [🍎🍎🍎🍎🍎] [🍎🍎🍎🍎🍎]
```

Teacher language:

> “There are two groups of five. Two fives make ten.”

### Stage 3 — Counting marks for small quantities

Introduce one vertical mark for one counted item. Use 1–5 first and connect every mark to an object.

```text
1 → |
2 → ||
3 → |||
4 → ||||
5 → one complete group of five marks
```

At this stage, the child may point, match or choose. The child does not need to produce neat written
strokes.

### Stage 4 — Bundled tally representation

When quantities become larger, show each group of five as one structured tally bundle. The bundle is a
visual unit, not a demand to recount all the strokes.

```text
1 bundle = 5 tally marks
2 bundles = 10
4 bundles = 20
8 bundles = 40
9 bundles = 45
10 bundles = 50
```

For a number with leftovers:

```text
41 = 8 bundles of 5 + 1 mark
42 = 8 bundles of 5 + 2 marks
43 = 8 bundles of 5 + 3 marks
44 = 8 bundles of 5 + 4 marks
45 = 9 bundles of 5
```

Use clear spacing, boxes, circles or ten-frame-style panels around bundles. Do not present 40–50 as a
crowded, unstructured row of strokes.

### Stage 5 — Numeral and number-name connection

After the structured quantity is visible, connect it to the symbol and spoken name.

```text
[|||||] [|||||] [|||||] [|||||] [|||||] [|||||] [|||||] [|||||]
8 groups of 5 → 40 → forty
```

For early classes, audio and object images are more important than reading the word “forty”. For older
children, add the number name after the child can model the quantity.

## Age-scaled application

| Class | Quantity range | Best representation | Typical playable game load |
|---|---|---|---:|
| Crèche | 1–3, naturally repeated | real objects, one mark, one/more | 5 familiar exposures where appropriate |
| Playgroup | 1–3, sometimes 1–5 | objects, fingers, simple marks | 5–6 targets |
| Nursery 1 | 1–5 | objects → numeral → simple counting marks | 6–7 targets |
| Nursery 2 | 1–10 | objects → groups → numeral → marks/tallies | 7–8 targets |
| Kindergarten | 1–20, extending when secure | ten-frames, groups of five, tally bundles, numeral | 8–10 targets |
| Primary/older | 1–100 and beyond according to the approved scheme | five-groups, ten-groups, tally records, numeral and number name | 8–10 targets per game; split larger ranges |

The item load is a guide. Increase toward ten only when the representation is familiar and the child can
explain or demonstrate it. Use fewer new representations when the concept itself is difficult.

## Example: Counting 40–50

Do not create one 11-question game simply because the range contains 11 numbers. Choose an age-appropriate
chunk such as 5–10 target numbers and use the rest in another ordered module.

### Module A — Bundle recognition

```text
Targets: 40, 41, 42, 43, 44, 45, 46, 47
Game items: 8
Objective: match structured groups/tally bundles to numerals.
```

### Module B — Complete the range

```text
Targets: 48, 49, 50 plus selected review targets
Game items: 5–8
Objective: connect bundles and extra marks to numerals and number names.
```

Module B stays locked until the required games in Module A/Unit 1 have been passed. If the curriculum
scope needs more practice, add a review module rather than overcrowding one game.

## Recommended follow-up lesson sequence

For a counting lesson that has already taught 1–10:

1. **Count the objects:** count 5–10 concrete objects and match the numeral.
2. **Build the groups:** arrange objects in groups of five or ten.
3. **Read the marks:** match each small quantity to counting marks/tallies.
4. **See the bundle:** identify 1–2 groups of five and connect them to 5 and 10.
5. **Transform the representation:** match objects, bundles, tally marks and numerals.
6. **Use the representation:** compare more/fewer, order quantities or answer a simple real-world question.

The follow-up lesson should be tagged as `reinforcement`, `new-representation` or `transfer`, and should
reference the original counting lesson with `reinforcementOf`.

## Game design patterns

### Object → tally

Show five apples, then offer 5–7 visual tally choices. The child taps the matching representation.

### Tally → numeral

Show five or more structured tally bundles. The child chooses the numeral. Read the prompt aloud.

### Numeral → bundle

Show `40`; offer 6, 7, 8, 9 or 10 bundles of five. The child selects the matching quantity.

### Bundle + extras

Show 8 bundles and 3 extra tally marks. The child chooses `41`, `42`, `43`, `44` or `45` as appropriate.

### Tally record

Show a simple class or market survey with 5–10 entries. The child compares which category has more or
fewer. Use Kindergarten/Primary only after the representation has been taught concretely.

## Teacher assessment

Look for whether the child:

- counts objects one-to-one;
- recognises a complete group of five;
- counts bundles before counting leftover marks;
- matches a structured representation to a numeral;
- explains with speech, pointing, movement, drawing or home language;
- transfers the idea to a new object or context.

Record `independent`, `with prompt`, `emerging` or `not yet observed`. Do not mark the child wrong merely
because the child counts every tally mark before learning to recognise the bundle.
