# Granular Weekly Lesson Plan and Game Specification

Create one completed file or record for every **class × termName × week × subject**. Use the exact term names `First Term`, `Second Term` and `Third Term`. Minimum: one record
per subject per week, ten records per subject per term. The game section is mandatory; it may state
that the game is adult-led Tier 0 for Crèche/Playgroup.

Use one action per objective. “Understand colours” is too broad; use “point to the red object from
two choices after the adult names red.”

Record exactly what the adult says for the key model and prompt. Use a consistent prompt ladder:
show/model → gesture → verbal clue → two choices → open choice.

### Recommended template by class

| Class | Preferred first choice | Typical weekly game examples |
|---|---|---|
| Crèche | tap-recognition / scene reveal | colour, sound, texture, body action, in/out |
| Playgroup | tap-recognition / matching | same object, shape hunt, animal sound, 1–3 objects |
| Nursery 1 | matching / tap-recognition / drag-sort | numeral-quantity, initial sound, AB pattern, routine order |
| Nursery 2 | matching / drag-sort / stage-sequence | word-picture, number order, living sort, handwashing |
| Kindergarten | quiz / fill-in-blank / game-chain / stage-sequence | addition story, sentence, pattern reasoning, safety choice |

## G. Teacher implementation script

```text
Teacher says:
Teacher shows:
Teacher waits:
Child may respond by:
If child is unsure:
If child succeeds:
If child disengages:
Closing phrase:
```

Use warm language such as “Let us try together”, “Show me another way” and “You noticed it”. Never
shame, force speech, remove comfort or continue after distress/fatigue.

## H. Publishing checklist

- [ ] Exactly one primary objective.
- [ ] At least one playable game seed exists for this subject/week.
- [ ] Game contains 5–10 playable items; quantity represented inside an item may be larger.
- [ ] Any oversized topic is split into age-appropriate series units/modules; unit count is not fixed.
- [ ] Follow-up/reinforcement games link to the earlier lesson and state the representation transformation where applicable.
- [ ] Game is linked to the correct class, term, week and subject ID.
- [ ] Concrete experience comes before symbolic/digital demand.
- [ ] Template and choice count fit the technical game band.
- [ ] Config contains required `gameId`, `template`, `lessonId`, `ageLevel`, `category`, `tier`,
      `item_id`, content collection, rewards and `successThresholdPct`.
- [ ] Scenario, character, hint, feedback and speech text are child-safe where supported.
- [ ] Images/audio are approved assets or documented fallback keys; no unreviewed external URLs.
- [ ] Game passes schema and pedagogy validation.
- [ ] Safety and ECCE review are recorded.
- [ ] Observation evidence and home link are present.
- [ ] The subject/week is counted in the coverage dashboard.
