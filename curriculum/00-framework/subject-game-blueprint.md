# Subject-by-Subject Game Blueprint

Use this blueprint when filling the annual 270-game register for a class. It gives each subject a
stable game vocabulary while allowing the objective and context to change each week. Never generate a
game from the subject name alone; combine this table with the class progression and weekly cell.

## 1. Communication and Early Literacy — `comm-literacy`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | respond to name, imitate sound, attend to picture/song | scene or tap reveal; no wrong state |
| Playgroup | point/name familiar picture, join rhyme, order two pictures | tap → matching → adult observation |
| Nursery 1 | rhyme, initial sound, picture vocabulary, retell 2–3 events | tap/matching → memory or picture quiz |
| Nursery 2 | blend orally, match familiar word/picture, retell beginning-middle-end | matching → stage-sequence → picture quiz |
| Kindergarten | read familiar words, answer story questions, build short sentence | matching → quiz/fill-in-blank after oral rehearsal |

**Asset rule:** show real objects, local names and picture cues. Any written option must be read aloud.

## 2. Pre-writing / Writing Skill — `writing`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | reach, grasp, release, make free marks | tap/reveal large colour or mark choice |
| Playgroup | copy vertical/horizontal line through movement or finger trail | tap/drag-sort route; no handwriting score |
| Nursery 1 | trace/copy lines, curves, circles, name mark | puzzle-split or drag-sort ordering strokes; optional mark-making offline |
| Nursery 2 | form selected letters, copy pattern, label a picture with support | matching letter/picture → puzzle or drag-sort strokes |
| Kindergarten | write name, familiar labels, short dictated sentence | matching word/picture → fill-in-blank or sentence order |

**Guardrail:** the game tests recognition or sequence, not pen pressure, neatness or motor speed. Real
writing is observed with an adapted grip and scribing route.

## 3. Numeracy / Mathematics — `numeracy`

### Number representation reinforcement

After a number range has been taught with real objects, schedule follow-up games that transform the same
quantity into groups, five-bundles, tally marks, numerals and number names. For example, after Counting
1–10, a later game may show 5 apples → one group of five → `|||||` → `5`. When work reaches 40–50, use
structured bundles of five rather than a crowded row of loose marks. The game may contain 8 playable
numbers while each number represents many objects.

Use `followUpType: "new-representation"` and `reinforcementOf` to connect the follow-up to the original
counting seed. Keep the game item count at 5–10; split larger ranges into logical ordered modules and
unlock the next unit only after all required games in the preceding unit pass.


| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | explore one/more, in/out, big/small during action songs | tap/reveal one object or two quantities |
| Playgroup | count actions/objects 1–3, same/different, big/small | matching quantity/object or tap choice |
| Nursery 1 | count and match 1–5, compare more/fewer, shape/pattern | matching → drag-sort → picture quiz |
| Nursery 2 | represent 1–10, order numbers, AB/ABB, compose small groups | matching → drag-sort/stage-sequence → quiz |
| Kindergarten | join groups, addition within 5, bonds, measure/pattern reasoning | game-chain concrete match → quiz/fill check |
| Primary | count larger ranges, bundled tallies, simple data records and number names | matching/drag-sort/quiz; split large ranges into ordered modules |

**Asset rule:** every numeral must be anchored to objects, fingers, dots or a ten-frame-style visual.
No timed arithmetic.

## 4. Pre-science and Nature — `science-nature`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | notice texture, light, water, sound and safe nature objects | tap/reveal with adult narration |
| Playgroup | match animal/sound, body part, weather or plant picture | tap → matching |
| Nursery 1 | identify senses, domestic animals, plant needs and weather | matching → drag-sort |
| Nursery 2 | classify living/nonliving, predict float/sink, sequence growth | drag-sort → stage-sequence → quiz |
| Kindergarten | observe materials, cause/effect, lifecycle and health phenomena | stage-sequence/label-diagram → game-chain/quiz |

**Asset rule:** use accurate, age-appropriate real or illustrated examples; avoid frightening imagery.

## 5. Social-Emotional Learning / Social Habits — `social-habits`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | seek trusted adult, accept turn, choose more/finished | scene/choice reveal; adult observes |
| Playgroup | greet, share, identify happy/sad/tired, follow routine | tap emotion/action → stage-sequence routine |
| Nursery 1 | name family/class roles, cooperate, ask for help, follow rule | matching person/action → picture quiz |
| Nursery 2 | sequence social problem repair, identify safe choice and community role | stage-sequence → drag-sort/quiz |
| Kindergarten | explain fair turn, solve simple conflict, identify responsibility/safety | game-chain scenario → quiz or stage-sequence |

**Safeguarding:** fictional scenarios only; do not require disclosure of personal harm or family details.

## 6. Health, Safety and Self-care — `health-selfcare`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | participate in wash, feed, rest and clean-up routines | adult-led scene/reveal |
| Playgroup | sequence handwashing, recognise safe/unsafe boundary with adult | stage-sequence → matching |
| Nursery 1 | demonstrate handwashing, tooth care, healthy food and stop/go safety | stage-sequence → matching/quiz |
| Nursery 2 | explain hygiene, nutrition, exercise, rest and trusted adult steps | stage-sequence → drag-sort → quiz |
| Kindergarten | apply safety rule, choose response, explain body-care routine | stage-sequence/label-diagram → game-chain/quiz |

**Guardrail:** no medical diagnosis, frightening injury content, food as reward or personal-data prompt.

## 7. Physical Development and Movement — `movement`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | reach, crawl, walk, clap, pause and dance safely | scene/reveal; device is secondary |
| Playgroup | imitate walk/run/jump/roll, balance and follow stop/go | tap movement picture → stage-sequence |
| Nursery 1 | coordinate locomotor route, throw/roll, fine-motor manipulation | matching movement/tool → drag-sort sequence |
| Nursery 2 | balance, throw/catch, cut/thread/build, follow movement sequence | stage-sequence → picture quiz |
| Kindergarten | plan safe movement, coordinate sequence and reflect on body | stage-sequence → game-chain |

**Guardrail:** never score athletic ability, body size or speed. Provide seated, low-impact and assisted
routes; physical play must happen away from the screen.

## 8. Creative Arts, Music, Rhymes and Pretend Play — `creative-arts`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | respond to beat, colour, voice and scarf movement | tap/reveal sound or colour |
| Playgroup | copy clap pattern, choose colour/texture, join pretend role | matching sound/action → memory |
| Nursery 1 | extend rhythm/colour pattern, sing refrain, create collage/role play | drag-sort pattern → tap/quiz choice |
| Nursery 2 | describe art choice, sequence a song/story, use local craft safely | stage-sequence → matching/quiz |
| Kindergarten | compose/extend pattern, perform, retell cultural story, reflect | game-chain → stage-sequence/quiz |

**Cultural rule:** invite local songs, stories, instruments and craft methods with community respect;
never present one culture as a costume or stereotype.

## 9. Digital Readiness — `digital`

| Class | Suitable objectives | Preferred game progression |
|---|---|---|
| Crèche | attend briefly with adult, stop when finished | one-button reveal; no independent use |
| Playgroup | tap a large target, listen, hand device to adult | tap-recognition with 2 choices |
| Nursery 1 | tap, match, replay audio and recognise feedback | matching/tap with 3 choices |
| Nursery 2 | drag with support, follow progress dots, use retry calmly | drag-sort/memory with 3–5 choices |
| Kindergarten | choose mode, follow a short chain, pause/exit safely | game-chain or template mix with 3–5 choices |

**Digital objective:** the child learns safe, accessible interaction—not device speed. A digital game
must always have an offline equivalent and an adult-supervised option.

## 10. Weekly authoring pattern

For each subject/week choose one pattern:

- **Exposure:** introduce one item with tap/reveal; ideal for Week 1 or younger learners.
- **Recognition:** choose or match a named item; ideal for Weeks 2–4.
- **Classification:** sort items by one visible property; ideal for Weeks 4–7.
- **Sequence:** put a routine, pattern, story or lifecycle in order; ideal for Weeks 6–9.
- **Transfer:** apply the skill in a new local setting; ideal for Week 7–9.
- **Consolidation:** revisit 3–5 previously taught items; ideal for Week 10.

The pattern changes, but the minimum remains one playable game for every subject in every week.
