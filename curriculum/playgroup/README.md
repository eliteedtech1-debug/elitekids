# Playgroup (2–3 years)

**Platform band:** `Creche` · **Primary purpose:** language, movement, sensory play, colours, shapes,
familiar animals and social routines.

Playgroup is still an early-development setting. Use real objects, songs, outdoor play, stories and
short guided choices. Formal worksheets and pressured letter writing are not required.

See `subjects/subject-map.md`, `schemes/three-term-scheme.md`, `lesson-plans/sample-weekly-plans.md`
and `lesson-notes/standard-notes.md`.
